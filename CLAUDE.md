# CLAUDE.md

You are working on the Unified IDP Camp Management System.

## Always Read First
1. `.claude/PROJECT_CONTEXT.md`
2. `PHASE_ORDER.md`
3. The current implementation phase file from `phases/`

## Stack
- Next.js Full Stack with App Router
- NextAdmin dashboard template
- TypeScript
- Neon PostgreSQL 18
- Drizzle ORM
- drizzle-kit `^0.31.7`
- Zod
- Tailwind CSS

## Dashboard Template
The project uses NextAdmin:
https://nextjstemplates.com/templates/nextadmin

Work inside the NextAdmin template structure. Reuse the existing dashboard shell, sidebar, header, dark mode, responsive layout, cards, tables, forms, and charts. Do not recreate the dashboard layout from scratch.

## Non-Negotiable Business Rule
Aid is managed at camp level only.
Do not implement family-level or individual-level aid distribution.
Families are registered only for statistics and population reporting.

## Development Method
For every phase:
1. Read the current phase file.
2. Propose Drizzle schema/table changes first.
3. Implement schema using `pgTable`, PostgreSQL types, and relations.
4. Generate migrations using `drizzle-kit`.
5. Implement backend services and permission checks.
6. Implement UI inside the existing NextAdmin structure.
7. Add Zod validation.
8. Add seed/demo data if useful.
9. Run lint, typecheck, and build.
10. Summarize what changed and what remains.

## Authorization Rules
- Enforce permissions on the server for every protected query and mutation.
- Never rely only on hidden frontend buttons.
- System Administrator can access all system data.
- Camp Manager can access only assigned camps.
- Providers can access only their own provider profile and contributions.
- Public beneficiaries can submit and track complaints only through public forms.

## Database Rules
- Use Neon PostgreSQL 18.
- Do not use MySQL syntax.
- Do not use Prisma.
- Use `drizzle-orm` and `drizzle-kit ^0.31.7`.
- Keep schema definitions in `src/db/schema`.
- Keep database connection in `src/db/index.ts`.
- Keep migrations generated by drizzle-kit.
